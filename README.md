# 프로젝트 소개문
\
본 프로젝트는 개인 블로그 사이트 구축을 목표로 한 `v0.1` 초기 개발 소스입니다.\
관리자 페이지 중심의 CMS 구조를 기반으로 게시판, 메뉴, 게시글, 댓글, 설정 관리 기능을 포함할 수 있도록 설계되었으며,\
`Spring Boot`, `Swagger API`, `PostgreSQL`, `Vue.js`, `Tailwind CSS` 등을 바탕으로 기본 구조를 구성하였습니다.\
또한 본 소스는 **OpenAI Codex의 도움을 받아 바이브코딩 방식으로 정리 및 구현된 프로젝트**이며, 향후 기능 확장과 운영 안정화를 위해 지속적으로 보완될 예정입니다.
\
# 프로젝트 추가 내용
\
`v0.1` 기준으로 게시판 관리, 메뉴 관리, 게시글 관리, 댓글 관리, 설정 관리 구조를 반영하였고,\
관리자 프론트엔드와 Swagger 기반 백엔드 API 연동, PostgreSQL 연계, Tailwind CSS 기반 화면 구성, 입력 검증 및 에러 메시지 처리 등 블로그 CMS의 기본 운영에 필요한 핵심 기능들을 초기 형태로 구성하였습니다.
\
# 릴리즈 버전
\
- `v0.1` - 개인 블로그 사이트 구축을 목표로 관리자 CMS 구조, API 연동, 데이터베이스 연결, 기본 UI 및 관리 기능을 포함한 초기 통합 버전입니다.
